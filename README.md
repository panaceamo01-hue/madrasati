# مدرستي — تطبيق تعليمي للتعليم الابتدائي

تطبيق تربوي تفاعلي بالعربية (RTL) للمستويات الستة من التعليم الابتدائي في المغرب، يعمل دون إنترنت ويحفظ التقدم على الجهاز.

## التشغيل

```bash
npm ci
npm run dev      # خادم تطوير على المنفذ 3000
npm run build    # فحص TypeScript + بناء الإنتاج إلى dist/
npm run preview  # معاينة بناء الإنتاج
```

## البنية

- `src/views/` — الشاشات: الرئيسية، المستوى، الدرس، الألعاب، الاختبارات، الحكمة، ملفي، الإعدادات، مساحة ولي الأمر.
- `src/data/` — كل المحتوى: `level1.ts` … `level6.ts` للدروس الأصلية، و`extras.ts` لدروس الرياضيات والنشاط العلمي الإضافية، و`games.ts` و`values.ts`.
- `src/games/` — الألعاب الست (ذاكرة، حساب، كلمات، مطابقة، ترتيب، قيم وأخلاق).
- `src/lib/` — التخزين المحلي `store.ts`، قواعد الفتح `unlock.ts`، مولّد الاختبارات `exam.ts`، تقرير ولي الأمر `report.ts`، المسار `router.ts`.
- `src/types.ts` — أنواع الدروس والخطوات.

## إضافة درس

أضف كائنًا إلى المصفوفة في ملف المستوى، بالشكل:

```ts
{
  id: 'l7-math-example',      // فريد
  level: 7,                    // غير مدعوم حاليًا: المستويات 1..6
  subject: 'math',             // arabic | math | islamic | science | social | french
  title: '...', emoji: '🔢', objective: '...',
  steps: [
    { kind: 'teach', title: '...', body: '...', visual: '...' },
    { kind: 'quiz', question: '...', options: ['...'], answer: 0, hint: '...' },
    { kind: 'order', question: '...', items: ['...'], hint: '...' },
    { kind: 'build', question: '...', word: '...', hint: '...' },
  ],
}
```

الترتيب في الملف يحدد تسلسل الفتح داخل المستوى، والنجاح في اختبار الدرس يفتح ما بعده.

## قواعد الفتح

- الدرس الأول في كل مستوى مفتوح؛ التالي يُفتح بعد إتمام الدرس السابق **واجتياز اختباره** (70%).
- المستوى التالي يُفتح بعد إتمام كل دروس المستوى السابق واجتياز اختباره.
- في مساحة ولي الأمر يمكن فتح مستوى الطفل فقط، أو من المستوى الأول حتى مستواه.

## النشر

كل push إلى `main` ينشر تلقائيًا على Vercel بعد ربط المستودع:

```bash
vercel git connect   # مرة واحدة
vercel --prod        # نشر يدوي عند الحاجة
```

## الحماية

لا تضع مفاتيح أو أسرار في المستودع؛ التطبيق لا يحتاج أي متغيرات بيئة، والتقدم محفوظ في `localStorage` على جهاز المستخدم.
